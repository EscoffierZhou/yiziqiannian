一、压缩包说明
================================================================
1. 一字千年_全站.zip
   完整站点（含全部音视频资源与文档）。解压后双击 index.html 即可观看入口 CG；
   正式浏览请从 main.html 进入，或直接把整个文件夹丢到任意静态服务器 / GitHub Pages。

2. 一字千年_源代码.zip
   仅源代码（HTML / CSS / JavaScript / data）。便于阅读与提交。
   注意：不含 audio 音频资源，单独打开会没有声音，需与全站包配合。

3. 一字千年_改动明细.diff.txt
   与原版逐行对比的改动明细（unified diff 格式）。

二、目录结构
================================================================
index.html                     入口 CG（星空 + 汉字隧道 + 黑金标题，黑金版）
main.html                      主站：序 → 竹简 → 纸 → 印刷 → 电 → 计算机 → 芯片 → AI → 尾
entrance.html                  备用入口页
yiziqiannian-entrance-cg.html  入口 CG 的单文件独立版
css/style.css                  全部样式（顶部含设计变量 :root）
js/main.js                     主站交互、滚动进度轴、音效与背景音乐引擎
js/sfx_data.js                 音效库（base64 内嵌 7 种音效，无需额外请求）
js/opening_audio_data.js       入口 CG 音乐的 base64 内嵌数据
data/key.bin                   本地配置/密钥数据
audio/                         音频资源（入口音乐、展馆 BGM、各类音效）

四、运行环境
================================================================
· 纯静态站点，无构建步骤、无需 Node。
· 本地预览：在站点根目录执行  python -m http.server 8777
            浏览器打开   http://localhost:8777/main.html
· 提示：main.html 通过 CDN 引用了 KaTeX（公式渲染）。离线打开时公式样式会缺失，
        其余功能不受影响；如需完全离线，可下载 KaTeX 到本地并改为相对路径引用。
