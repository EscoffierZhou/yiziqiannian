# 一字千年 · 从竹简到芯片的中国信息之路

> 让一个汉字「国」穿越竹简、纸、印刷、电、计算机、芯片与人工智能。从竹简到芯片的中国信息之路。

---

## 📖 项目简介

《一字千年》是一部融合**东方审美**与**现代数字化科技叙事**的前端交互作品。作品以汉字**「国」**的千年演进为暗线，以人类文明**信息载体**的形态变迁为明线，构建了一条双线并行的信息文明之路：

- **01 竹简（记录）**：西周金文初文「或」（以兵守疆）至汉隶「國」的 9 根竹简演进链，支持惯性拖拽、滚轮缩放与 HUD 扫描。
- **02 纸（轻盈）**：楷书繁体「國」逐步定型，真实物理阻尼拖拽与信息轻重对比滑杆。
- **03 印刷（复制）**：雕版印刷与毕昇活字印刷，阵列排布与规模化复制爆发。
- **04 电与通信（传递）**：电报老中文电码 **`0948`**、电话音频模拟波形、早期终端光标闪烁。
- **05 计算机（编码）**：全剧高光时刻，数字化形变过渡（繁体「國」 $\rightarrow$ 简体「国」），真实 GB2312/Unicode/UTF-8 粒子解构与二进制流重组。
- **06 芯片（计算）**：微处理器与纳米走线，字符、编码、存储、计算、传输 5 大微观区域电路激活。
- **07 人工智能（理解）**：AI 语义流网络（字形 $\rightarrow$ 字符 $\rightarrow$ 编码 $\rightarrow$ 数据 $\rightarrow$ 模型 $\rightarrow$ 语义 $\rightarrow$ 内容 $\rightarrow$ 传播），理解与生成。
- **尾声（凝聚）**：汇聚各时代信息粒子，凝铸用户留下的专属汉字。

## 🛠️ 技术特性

- **纯前端零外部依赖**：仅基于原生 HTML5 + CSS3 + Vanilla JavaScript + Canvas + SVG 构建，无外部第三方网络库或 CDN 依赖，保证在任何网络环境下毫秒级极速渲染。
- **全屏沉浸与黑金视觉**：黑金配色（深墨黑 `#0B0C0E` + 古铜金 `#B89A62` + 数字青 `#72D6D0`），高保真字形动画与微交互。
- **全端响应式适配**：完美适配桌面端大屏与移动端触摸交互。
